@19h47/radiogroup

Enhance APG radio groups. Do not replace native radios.

You write role="radiogroup" / role="radio"; the script keeps exclusive selection, keyboard, and attributes in sync. If a fieldset and input type="radio" are enough — including cards or ratings with :has() — skip the library. Pattern: WAI-ARIA Radio Group.

Usage

Use this when the markup is already APG. For a form, prefer native radios. 

import RadioGroup from '@19h47/radiogroup';

const $element = document.querySelector('[role="radiogroup"]');
const radiogroup = new RadioGroup($element);

radiogroup.init();
<div role="radiogroup" aria-labelledby="crust-label">
	<h2 id="crust-label">Pizza crust</h2>
	<div aria-checked="true" tabindex="0" role="radio">Regular</div>
	<div aria-checked="false" tabindex="-1" role="radio">Deep dish</div>
</div>

Time slots

App chrome, not a form. Each option is a composite cell (day, time, seats left). Full slots are skipped by the arrow keys. Party size closes tables that are too small and clears an invalid selection. A native radio list would not keep this layout or the live summary.
