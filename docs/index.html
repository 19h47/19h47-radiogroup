@19h47/radiogroup

Exclusive radio groups with keyboard support

Markup is the source of truth (role="radiogroup", role="radio", aria-checked, tabindex). The script only enhances selection and keeps attributes in sync, following the WAI-ARIA Radio Group pattern.

Usage

import RadioGroup from '@19h47/radiogroup';

const $element = document.querySelector('[role="radiogroup"]');
const radiogroup = new RadioGroup($element);

radiogroup.init();
<div role="radiogroup" aria-labelledby="crust-label">
	<h2 id="crust-label">Pizza crust</h2>
	<div aria-checked="true" tabindex="0" role="radio">Regular</div>
	<div aria-checked="false" tabindex="-1" role="radio">Deep dish</div>
</div>

tagger + template

Radios are appended from tagger through template(label, value, selected, name).

	name: 'japan-condiments',
	tagger: [
		{ label: 'Black vinegar', value: 'black_vinegar', selected: true },
		{ label: 'Chili oil', value: 'chili_oil', selected: false },
	],
	template,
});
